# HomeWork Laba7
### Домашняя работа (Условие)
17.
Вычислить для заданного натурального `n` и действительного `x` с использованием цикла `for` значение: sin x + sin x^2 + ... + sin x^n


### 1. Алгоритм

1. Начать программу.
2. Объявить переменную `n` типа `int`.
3. Объявить переменные `x` и `sum` типа `double`.
4. Ввести с клавиатуры значения `n` и `x`.
5. Присвоить переменной `sum` значение `0`.
6. Организовать цикл `for` от `1` до `n`.
7. На каждой итерации вычислить `sin(x^i)` и добавить результат к `sum`.
8. Вывести полученную сумму на экран.
9. Завершить программу.

# 2. Реализация программы
Программа реализована на C.

Библиотека `math.h` подключена для использования математических функций.

Для ввода значений используется функция `scanf()`.

Для вычисления суммы используется цикл `for`.

Для вычисления степени числа используется функция `pow()`.

Для вычисления синуса используется функция `sin()`.

`sum +=` — оператор, который добавляет очередное значение к общей сумме.


# 3. Результаты работы программы
Программа вычисляет сумму синусов степеней числа `x` от первой до `n`-й степени.

Контрольный пример:

Ввод: `3 2`
Вывод: `1.285399`
